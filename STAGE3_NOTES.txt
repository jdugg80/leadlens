LeadLens Stage 3 Update
Version: 1.3.0

Included in this package:
- package.json version bumped to 1.3.0
- app.json Expo version bumped to 1.3.0
- New flexible export system:
  - Sales Template export
  - Standard generic spreadsheet export
  - Custom template upload
  - Manual column-to-field mapping
  - Saved export profiles for reuse
- Improved lead normalization before save/export
- Stronger industry vertical identification and automatic property-type suggestion
- Better handwriting uncertainty handling in image extraction prompt
- Fixed Review screen intro-email function collision bug
- Repaired Capture screen Excel import flow and cleanup

Files in this patch:
- package.json
- app.json
- src/screens/ExportScreen.js
- src/screens/CaptureScreen.js
- src/screens/ReviewScreen.js
- src/utils/exportProfiles.js
- src/utils/leadProcessing.js
- src/utils/claudeApi.js

Recommended steps:
1. Back up your current project.
2. Replace these files in your working LeadLens project.
3. Delete any desktop.ini files if Windows sneaks them back in.
4. Run:
   npm install
   npx expo start -c
5. If Android native resources act up again, run:
   npx expo prebuild --platform android --clean

Notes:
- Saved export profiles are stored in AsyncStorage under @leadlens_export_profiles.
- Standard export gives you a general-purpose Excel file when no template is needed.
- Custom template mapping currently targets the first worksheet in the uploaded file.
