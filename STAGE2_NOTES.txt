LeadLens Stage 2 Update

Included in this package:
- Multi-prospect extraction from a single image
- New Batch Review screen for reviewing/editing multiple extracted leads before saving
- Stronger AI extraction prompt for multiple cards, storefronts, screenshots, and handwriting uncertainty
- Deeper enrichment pass for missing phone, email, and address/location fields
- Better storefront location enrichment using GPS + OpenStreetMap lookup
- Lead normalization improvements for phone, email, state, zip, and names before save/export
- Export normalization updated to keep names/address fields clean
- Desktop.ini junk files intentionally excluded from this package

Files in this patch are meant to be applied on top of the Stage 1 project.

Apply these files into your existing LeadLens project, then rebuild.

Recommended rebuild:
1. Delete any desktop.ini files if Windows drops them back into the project
2. npx expo prebuild --platform android --clean   (only if Android native resources get weird again)
3. npx expo start -c
4. eas build -p android   or   npx expo run:android

Not included yet:
- Custom Excel template upload + manual field mapping
- Handwriting-specific preprocessing pipeline beyond the stronger AI prompt
- Saved reusable mapping profiles for arbitrary spreadsheet schemas
