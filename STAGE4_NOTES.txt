LeadLens Stage 4 Update
Version: 1.4.0

Included in this package:
- True multi-prospect extraction from a single image via Claude array response (`extractLeadsFromImage`)
- New Batch Review screen for reviewing, editing, skipping, and saving multiple leads at once
- Duplicate lead-in-queue detection for both single review saves and batch saves
- Settings screen for scheduled auto export + email setup
- Best-effort scheduled export/email trigger when the app is opened or returns to foreground after the scheduled time
- Review screen duplicate warnings and fixed intro-email helper bug
- Capture screen cleanup and rebuilt image / gallery / spreadsheet import flow
- Version bump to 1.4.0 in app.json and package.json

Important limitation on scheduled auto export/email:
- This package can automatically queue the export into the device mail composer when the app is active or brought back to the foreground around the scheduled time.
- It does NOT provide true background unattended emailing. That would require a backend/server or a dedicated automation service.

How to apply:
1. Back up your current LeadLens project.
2. Copy these files into the matching locations in your project.
3. Rebuild the app.

Recommended rebuild:
- npm install
- npx expo start -c

If Android native resources get weird again:
- npx expo prebuild --platform android --clean
